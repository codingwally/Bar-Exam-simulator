Law school examination

Examination Room

One guided class flow for preparing, taking, grading, and releasing an examination.

Beta access
One examination, six classroom stages

A clear handoff from Admin to final results

Each person sees only the work needed for the next classroom stage. The Professor remains in control of the examination and every result released to a student.

  1. Stage 1Admin opens the roomCreates one Professor room key for one Examination Room.
  2. Stage 2Professor publishesUploads questions, checks them, sets the schedule, and publishes the exam.
  3. Stage 3Beadle prepares the classUses the Beadle key and saves the class list. Due Diligence then creates the student exam code for the Beadle to copy.
  4. Stage 4Students take the examSign in, enter the student exam code, answer, review, and submit.
  5. Stage 5Professor gradesChecks submissions, records grades, and adds comments.
  6. Stage 6Professor releases resultsSends final results to the class or downloads a selected candidate PDF.
Where does the student exam code come from? After the Beadle confirms a valid class list, Due Diligence activates the class-wide code and queues one private email to each listed student. No examination link or per-student approval is required.
Student sign-in is required. A student cannot open the Student examination page until signed in. Every student must also be on the class list.
During a monitored examination, copy, cut, and paste are blocked. Leaving the exam tab is recorded for the Professor and Beadle to review. It is not an automatic failure.
