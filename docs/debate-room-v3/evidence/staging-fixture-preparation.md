## Deployment and rollback proof provenance

The V3 source explicitly authorizes implementation, controlled testing and protected preview (line 25). Acceptance F05 requires migration rollback on controlled data (line 528), but does not mandate a hosted installation-under-rollback before a restricted preview. An exact candidate on the specifically trusted Debate branch can therefore be staged without merging or launching publicly, provided the superior task's ownership clearance, exact source/scope, baseline preservation and closed feature/provider/mail gates remain enforced.

No change to a shared/superior workflow follows automatically from this observation.
