# Examination Room instructions

Production entry: https://duediligence.ph/#examination-room

The Examination Room has two public workspaces: **Professor** and **Student**. The signed-in account is always checked by the server. An examination code identifies the class examination, but it never replaces sign-in or the saved class list.

## 1. Professor

### Prepare and publish an examination

1. Sign in using the Professor account registered for the Examination Room.
2. Open **Examination Room**, then choose **Professor**.
3. If this is a new room, submit the room request and redeem the one-time Professor key after it is issued. If the room already exists, select it from **Your examinations**.
4. Create the examination, add or upload the questions, and review every question and point value.
5. Set the opening and closing times, duration, permitted materials, navigation rule, focus-change rule, and the instructions students must read.
6. Review the final student view and publish. Give the designated Beadle only the Beadle key. The Beadle key is not the student examination code.
7. Confirm the class list and issue the class examination code. Each student must sign in with the exact email saved on that list.

### Monitor the live room

1. Open the published examination and choose **Enter virtual room**.
2. The live table shows each student's name or exam number, authenticated **Access email**, current status, last connection, and active-session count. Active answers are not shown in this monitor.
3. Choose **Refresh now** if you do not want to wait for the automatic 15-second refresh.

### Kick out, block, and unblock

- **Kick out** closes all active sessions for that student. The student may sign in and enter again if the examination is still open and all normal checks pass.
- **Block** closes all active sessions and prevents a new session. The block remains until a Professor chooses **Unblock**.
- **Unblock** restores normal entry checks; it does not bypass sign-in, the class list, schedule, or examination code.

For every action:

1. Choose the action beside the correct student.
2. Enter a clear reason.
3. Read and check the acknowledgement.
4. Confirm the action.

Kick, block, and unblock are each saved as separate audit events. If a student reports an error, verify the authenticated email before changing access.

### Grade and release

1. When submissions are available, open **Grade submitted exams**.
2. Save each score and comment, finalize the grades, and review the class-results dashboard.
3. Download the workbook if needed, then release results only after the final review.

## 2. Student

### Enter the examination

1. Sign in with the exact email address placed on the Professor's confirmed class list.
2. Open **Examination Room**, then choose **Student**.
3. Enter the current class examination code.
4. Check **I reviewed the Professor's instructions and am ready to enter**, then choose **Enter examination**.
5. Review the readiness checks and published rules. Start only after all required checks pass.

### Take and submit the examination

1. Answer each question in the examination workspace. Use **Flag** for questions you want to revisit.
2. Watch the saved/synced indicator. Clipboard and right-click remain available. A Professor may choose to record focus changes in the published rules, but a focus event never automatically fails, locks, submits, closes, or erases the examination. Camera collection is off.
3. If the connection drops, keep the page open. Work can remain saved on that device until the connection returns. Do not clear browser data.
4. Do not write in a second tab. A second tab is read-only while another tab holds the active writing session.
5. Choose **Review All Answers**, confirm the final review, and submit.
6. Keep the server-issued submission receipt. Use **Download my answer copy** if it is offered.

Question flags remain attached to the same authorized attempt after a legitimate reconnect. A different device can restore only work that already reached the server.

### If access is ended

- If the Professor **kicks you out**, your current session closes. You may try to enter again while the examination is open.
- If the Professor **blocks you**, a new session will be denied. Contact the Professor and provide the exact email shown on your signed-in account. Only a Professor's **Unblock** action restores normal entry checks.

Do not use another person's account or share a Professor key, Beadle key, or grading key. The class examination code is an additional entry check, not proof of identity.
